todo-cli v1.3



Список задач



Функции:

\-Показать задачи (show)



\-Добавить задачу (add)

&#x20;   -Возможность задать приоритет при создании задачи

&#x20;   -Возможность задать дату для задачи



\-Отметить задачу, как выполненную (done)



\-Очистить все выполненные задачи (clear)



\-Удалить задачу (delete)





Необходим Python 3.10+
