\# SimpleToDo



Консольный список дел на Python. Задачи имеют приоритет и срок выполнения, автоматически сортируются и сохраняются в файл, поэтому не пропадают после закрытия программы.



\## Возможности



\- добавление задач с названием, приоритетом и сроком

\- автоматическая сортировка списка

\- отметка задач выполненными

\- редактирование срока и приоритета

\- удаление одной задачи или очистка всех выполненных

\- сохранение в JSON после каждого изменения

\- защита от неверного ввода и повреждённого файла данных



\## Требования



\- Python 3.10 или новее (используется `match/case`)

\- сторонние библиотеки не нужны



\## Запуск



```bash

git clone https://github.com/godsatellite/todo-cli.git

cd todo-cli

python todo.py

```



В Windows можно запускать через лаунчер с нужной версией, например `py -3.12 todo.py`.



\## Команды



| Команда | Что делает |

|---------|-----------|

| `show` | показать все задачи |

| `add` | добавить задачу |

| `done` | отметить задачу выполненной |

| `edit\_date` | изменить или убрать срок задачи |

| `edit\_priority` | изменить приоритет задачи |

| `delete` | удалить задачу |

| `clear` | удалить все выполненные задачи |

| `exit` | выйти из программы |



Команды не зависят от регистра: `Show` и `SHOW` сработают так же, как `show`.



\## Как это работает



\*\*Приоритет:\*\* `1` высокий, `2` средний, `3` низкий. Приоритет необязателен: пустой ввод или неверное значение дают «пустой» приоритет.



\*\*Срок:\*\* дата в формате `ГГГГ-ММ-ДД`, например `2026-10-25`. Пустой ввод означает «без срока». При редактировании пустой ввод отменяет изменение, а `-` убирает срок.



\*\*Сортировка.\*\* Список всегда упорядочен так:



1\. невыполненные задачи выше выполненных

2\. внутри группы по сроку (чем раньше, тем выше, задачи без срока в конце)

3\. при равных сроках по приоритету (задачи без приоритета в конце)



Номера задач в командах `done`, `edit\_date`, `edit\_priority` и `delete` берутся из текущего порядка, поэтому перед выбором программа показывает пронумерованный список.



\## Пример



```

Выберите действие: add



Введите задачу: Сдать лабораторную



Задайте приоритет: (1 - высокий, 2 - средний, 3 - низкий) 1



Введите дату для задачи: (Формат YYYY-MM-DD) 2026-11-03



Добавлена задача: Сдать лабораторную



Выберите действие: show



\[Высокий приоритет] 1. Сдать лабораторную ⬜ Дата: 2026-11-03

```



\## Хранение данных



Задачи сохраняются в файл `tasks.json` рядом с `todo.py`, независимо от того, откуда запущена программа. Файл создаётся автоматически при первом изменении и исключён из репозитория через `.gitignore`.



Если `tasks.json` повреждён, программа сообщает об этом и завершается, ничего не перезаписывая. Исправьте файл вручную или удалите его.



Формат одной задачи:



```json

{

&#x20; "title": "Сдать лабораторную",

&#x20; "done": false,

&#x20; "priority": 1,

&#x20; "date": "2026-11-03"

}

```
